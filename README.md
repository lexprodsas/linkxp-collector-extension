# LinkXP - Extension Chrome LinkedIn Stats Collector

Extension Chrome pour collecter automatiquement les statistiques LinkedIn et les envoyer vers LinkXP.

## 🎯 Fonctionnalités

- ✅ Collecte du profil (abonnés + compétences)
- ✅ Liste des publications récentes
- ✅ Bouton "Suivre" sur chaque post LinkedIn
- ✅ Collecte des stats (impressions, réactions, commentaires, republications)
- ✅ Stockage local pour tests
- ✅ Prêt pour synchronisation API
